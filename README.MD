# Projetos Integradores

Aqui estão alguns projetos que desenvolvi para praticar lógica de programação em Python, manipulação de dados e arquivos JSON e TXT.

Os projetos foram feitos durante meus estudos, com o objetivo de colocar em prática o que estou aprendendo e melhorar minhas habilidades em programação.

## 1. Sistema de Cadastro de Alunos

O primeiro projeto é um sistema de cadastro de alunos. O exercício tinha como objetivo criar um programa que permitisse cadastrar e gerenciar informações de alunos.

### Funcionalidades

- Cadastrar aluno
- Listar alunos
- Pesquisar aluno
- Remover aluno
- Salvar alunos
- Carregar alunos
- Sair

Cada aluno possui:

- Nome
- Idade
- Notas

### Conceitos utilizados

- Listas
- Dicionários
- Funções
- Estruturas condicionais (`if/else`)
- Laços de repetição (`while`)
- Manipulação de arquivos

## 2. Sistema Bancário

O segundo projeto é um sistema bancário. Nesse exercício, o objetivo era criar um programa utilizando uma classe para representar contas bancárias.

### Funcionalidades

- Criar conta
- Depositar
- Sacar
- Consultar saldo
- Listar contas
- Sair

A estrutura principal do projeto utiliza a classe:

```python
class Conta:
    ...
```

Cada objeto representa uma conta bancária.

O exercício também propõe salvar os dados em um arquivo para que as informações possam ser recuperadas posteriormente.

### Conceitos utilizados

- Classes e objetos
- Métodos e atributos
- Construtor `__init__`
- Listas e dicionários
- Estruturas condicionais
- Manipulação de arquivos

## 3. Sistema de Biblioteca

### Funcionalidades

- Cadastrar livro

- Pesquisar livro
- Cadastrar usuário
- Listar usuários
- Emprestar livro
- Devolver livro
- Salvar dados
- Carregar dados
- Sair

Cada livro possui:

- ID
- Título
- Autor
- Ano de publicação
- Disponibilidade

Cada usuário possui:

- ID
- Nome
- Idade

As principais classes do projeto são:

```python
class Livro:
    ...

class Usuario:
    ...

class Biblioteca:
    ...
```

### Conceitos utilizados

- Variáveis e tipos de dados
- Estruturas condicionais (`if`, `elif` e `else`)
- Laços de repetição (`for` e `while`)
- Funções e métodos
- Listas e dicionários
- Classes e objetos
- Construtor `__init__`
- Manipulação de arquivos JSON
- Salvamento e carregamento de dados
- Conversão de dados
- Controle de empréstimos e devoluções

## Tecnologias utilizadas

- Python
- JSON
- Arquivos TXT
